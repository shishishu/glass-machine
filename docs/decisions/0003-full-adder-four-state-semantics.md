# ADR 0003：全加器四态结构语义（Full-adder Four-state Structural Semantics）

- 状态：已接受，适用于 M1 首次交付。
- 日期：2026-10-26。

## 问题与选择（Problem and Decision）

二态全加器的整数和、五门结构与多数表决进位公式等价，但四态逐门传播丢失输入相关性，等价变换可能改变未知态精度。例如 A=1、B=X、Cin=1，所有二态补全都有 Cout=1；五门结构中 p=X、g=X、h=X，因此 Cout=X。

本阶段选择固定五门 Detailed 结构作为未知传播规格。输入 Z 在门求值时视为 X；Reference 用显式结果表独立表达该结构的稳定语义，Fast 也保留同等保守程度。二态的独立数学依据仍是整数加法。

完整表格与公开接口见[首次交付规格](../specifications/m1-combinational.md)。公开文档和界面应解释上述示例，不能将 X 称为算术错误或真实物理电平。

## 原因与替代方案（Rationale and Alternatives）

本阶段目标是观察门结构如何产生计算和传播。将 Reference 的最精确二态补全结果直接要求 Detailed 满足，会把抽象差异误判成缺陷；修改 Detailed 来返回理想值则会隐藏实际内部结构。

可选方案包括只比较二态、允许四态精度偏序、引入保留相关性的符号仿真。当前显式结构表最小、可穷举、便于解释，因此暂不增加符号执行系统。未来改变拓扑或抽象时应重新声明四态比较域。

## 影响与验证（Consequences and Validation）

保留 M0 固定传输延迟与逐事件输入规则；无需改动调度内核。全部 64 组输入按结构表比较，8 组二态额外对照数学公式；波形和因果由独立时序测试验证。共享基础类型是共同依赖，不能因模型文件分离就声称完全独立。此决策不涉及晶体管、寄存器或物理时序校准。
