# M0 validation report

M0 validates the NOT vertical slice through independent paths:

1. literal four-state truth-table cases in tests;
2. `ReferenceNot`, implemented as an immutable table;
3. `NotGate`, implemented as an event-driven detailed component;
4. `FastNot`, implemented through an independent translation path.

All four inputs `0`, `1`, `X` and `Z` are compared exhaustively.

Additional properties cover:

- deterministic trace digests across independent runs;
- causal input-to-output event links and declared delay;
- JSONL trace round-trip equality;
- experiment replay by recomputation;
- stable-state snapshot and restore;
- explicit width and driver failures;
- oscillation detection through the event budget;
- GUI controller state derived from the same committed simulation trace.

M0 does not claim physical transistor verification. ngspice enters in M1 for selected local circuits.
