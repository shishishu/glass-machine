# 数字逻辑规范 v1（Digital Logic Specification v1）

本规范定义 M0 可执行模型的逻辑值、向量、NOT 语义和驱动约束。它描述数字抽象，不描述连续电压。

## 四态逻辑值（Four-state Logic Values）

M0 使用四个显式状态：

- `0`：被驱动的逻辑低电平；
- `1`：被驱动的逻辑高电平；
- `X`：未知、未初始化或发生冲突后无法确定的逻辑值；
- `Z`：未驱动／高阻态（high impedance）。

`X` 不是第三种稳定逻辑电平，`Z` 也不是可直接参与布尔运算的普通数值。二者的作用是让“不知道”和“没有驱动”在模型中显式暴露，避免悄悄把异常当作 `0` 或 `1`。

## 逻辑向量与位宽（Logic Vectors and Bit Widths）

- 向量不能为空；
- 位宽必须显式；
- 文本表示按最高有效位在前（MSB-first）书写；
- 位宽不匹配是错误；
- GlassMachine 不静默截断，也不自动扩展。

M0 的 NOT 示例宽度为 1 位，但底层逻辑向量并没有把整个项目锁定为 1 位或 8 位。后续 CPU 数据宽度、地址宽度、Memory 事务宽度和加速器数值类型将分别声明。

## NOT 语义（NOT Semantics）

M0 的 ground truth 真值表为：

| 输入 | 输出 | 解释 |
| --- | --- | --- |
| `0` | `1` | 已知低电平取反 |
| `1` | `0` | 已知高电平取反 |
| `X` | `X` | 未知输入无法产生已知输出 |
| `Z` | `X` | 未驱动输入没有建立可确定的布尔电平 |

其中 `Z → X` 是数字模型语义，不是对晶体管节点电压的声明。实际悬空节点如何变化，需要器件模型、寄生参数和 SPICE 瞬态仿真支撑。

## 固定传输延迟（Fixed Transport Delay）

自 2026-09-06 的 M0 修正起，组合逻辑明确采用以下传输延迟规则：

1. 每个组件使用固定、非负整数 `delay`，以模型 tick 为单位；组件无内部时序状态。
2. 初始化及每次输入信号实际变化时，立即读取输入快照并求值。
3. **每次求值的每个输出都入队**，保存当次结果，在求值时刻加 `delay` 后尝试提交。
   后续输入不取消、不覆盖先前安排的输出；不能因为拟议值等于当前线路值就在入队前跳过。
4. 只有出队提交时才比较新旧值：相等则不产生 `TraceEvent`，也不通知下游；
   该待处理项仍消耗事件预算、序号并推进模型时间。
5. 非零延迟事件的 `delta=0`；零延迟事件在当前时刻的下一 delta 提交。
   同键事件由 `sequence` 排序；同时刻输入是逐事件提交，不是原子批量更新。
6. 输出事件的 `caused_by` 指向触发本次求值的输入变化事件；初始化没有父事件。
   多输入组件的此字段表示直接触发者，不表示所有输入值的完整来源集合。

对已完成初始传播的单个 NOT，输出波形是输入波形取反后平移 `delay`；
同一时间有多个转换时，还需按 delta 和 sequence 查看顺序，不能只比较时间戳。
例如初始 `input=1、output=0`，`delay=3`：

| 输入转换 | 对应输出转换 |
| --- | --- |
| `t=7: 1→0` | `t=10: 0→1` |
| `t=8: 0→1` | `t=11: 1→0` |
| `t=9: 1→0` | `t=12: 0→1` |

短脉冲不会被过滤。重复输入不产生变化事件；`X→Z` 的 NOT 结果同为 `X`，
不要求每个输入事件都对应输出变化事件。验证必须检查完整预期波形及因果关系，不能只检查最终值。

用户可以使用 `set_input()` 后调用 `run_until_stable()` 等待稳定，也可以预先安排连续输入。
后者按有限序列运行；无限时钟、寄存器、惯性延迟、脉冲过滤、模拟电压与物理时间校准均不属于本次修正。
决策与兼容性说明见 [ADR 0002](../decisions/0002-fixed-transport-delay.md)。

## 驱动规则（Driver Rules）

M0 中每个信号只允许注册一个驱动者：

- 外部输入由实验 API 驱动；
- 组件输出由对应组件端口驱动；
- 构造电路时注册第二个驱动者会立即失败；
- M0 不尝试解析多个驱动者之间的竞争。

多驱动解析表、三态总线和冲突产生 `X` 的规则将在确实引入总线时单独规范，不能仅凭四态值已经存在就声称完成。

## 错误语义（Error Semantics）

以下情况必须明确报错，不能静默修复：

- 输入包含 `0`、`1`、`X`、`Z` 之外的字符；
- 构造空向量；
- 端口与信号位宽不一致；
- 重复注册信号或组件；
- 为单驱动信号注册第二个驱动者；
- 事件超过配置预算而无法达到稳定态。
